# Report design
Mode: Read. Code-first per project instructions and approved plan.
White paper, dark navy ink (#172c3b), teal links (#00656b), warm gray rules (#d9dedb). Georgia text at 19px/1.7, system sans navigation. Narrow 70ch text measure with a quiet left contents rail on large screens. No imagery, cards, motion or dashboard treatments. Dates carry the timeline. Mobile moves contents above the narrative. Focus is a visible 3px outline. Print uses 10.5pt text with generous leading and compact references.
